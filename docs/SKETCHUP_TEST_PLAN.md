# SketchUp 実機テスト手順

Ruby 単体テスト（`rake test`）では、幾何エンジンと SketchUp アダプタのモック動作を検証しています。
以下は **実機でしか確認できない項目** です。SketchUp 2021 / 2024 以降（Windows・Mac）で確認してください。

結果は「OK / NG / 気になった点」を記録し、NG の場合は Ruby コンソールの `[StoneLayout]` ログを添えてください。

## 0. 準備

1. Extension Manager から `dist/*.rbz` をインストール（または `src/` 以下を Plugins フォルダにコピーして再起動）
   - [ ] ツールバー「石割付 Stone Layout」に 3 つのボタンが出る（Windows: SVG / Mac: PNG アイコン）
   - [ ] 何も選んでいないとき「目地を編集」「割付設定を変更」はグレー、面を選ぶと「石割付を生成」が有効
   - [ ] ボタンにマウスを乗せるとツールチップ、ステータスバーに説明
2. ウィンドウ → Ruby コンソール を開いておく（エラーとログが出る）
3. モデル情報 → 単位 を「mm」にしておく（数値入力の解釈を確認するため）

## 1. 平面壁（仕様 18-1）

1. 幅 5000 × 高さ 3000 の鉛直な長方形を描き、その面を選択
2. 右クリック →「石割付を生成...」
3. 石幅 900 / 石高さ 600 / 目地 8 / 石厚 30 / 芋目地 / 左端・下端
   - [ ] 最初はパターン・石の幅/高さ・目地幅・石厚だけが見え、それ以外は「割付・収まりの詳細」に畳まれている
   - [ ] 平面壁では「開始位置」「折れ点」「曲面の表示」が出ない（丸柱・折れ壁・R面でだけ出る）
   - [ ] ダイアログ上部の展開図と、モデル上の青線プレビューの両方が出る。統計が「30 枚 · 5 段 · 端の石 左 900 mm ／ 右 500 mm」
   - [ ] OS のライト／ダーク設定に合わせて配色が変わる
   - [ ] 値を変えると 0.3 秒ほどでプレビューが更新される
4. 「生成」
   - [ ] アウトライナに `StoneLayout_001` と `Stone_0001`〜`Stone_0030`
   - [ ] 各石が閉じたソリッド（エンティティ情報で「ソリッドグループ」、体積表示あり）
   - [ ] 目地の隙間が 8mm（メジャーで確認）、石厚 30mm、石の表面が元の面と同一平面
   - [ ] 元の面は削除されていない。既存の材質・タグが変わっていない
   - [ ] 生成後、そのまま目地編集モードに入り、編集パネルが表示される
5. 馬踏み目地・左右均等・全体均等・右端・中央も試す

## 2. 目地ドラッグ（仕様 18-2、最重要）

1. 縦目地にカーソルを合わせる → [ ] オレンジにハイライト
2. クリック → [ ] 青で選択。ステータスバーに位置
3. 右へドラッグ（押したまま動かす）。また「クリック → マウスを動かす → もう一度クリック」でも同じように動くこと
   - [ ] 移動後の目地が緑、変わる石の輪郭が黄色で追従
   - [ ] 既存目地・壁端・壁中央の近くでスナップし、ラベルにスナップ先が出る
   - [ ] Alt（Mac: Command）を押している間はスナップしない
   - [ ] 隣の目地を越える／最小寸法未満／壁の外 → 赤表示と理由が出る
   - [ ] ドラッグ中に形状（石グループ）は書き換わらない
4. 離す（またはもう一度クリック） → [ ] 左右 2 枚の石だけが再生成される（他の石はアウトライナ上も変化なし）
5. 選択したまま `100` と入力して Enter → [ ] 100mm 移動
6. ドラッグ中に `100` と入力 → [ ] ドラッグしている向きに 100mm
7. 編集 → 元に戻す → [ ] 1 回で目地 1 本分が戻る。データも戻る（再度ドラッグして位置が正しい）
8. やり直し → [ ] 再適用される
9. ドラッグ中に Esc → [ ] 取り消し。もう一度 Esc → 選択解除
10. ドラッグ中に別ツール（スペースキーで選択ツール）へ切替 → [ ] エラーなく終了、形状は変わらない
11. Shift + クリックで通り目地 → [ ] 連続する目地が全部選択され、まとめて動く
12. 横目地（馬踏み）を通りで動かす → [ ] 上下の縦目地が伸び縮みして T 字がつながったまま

   - [ ] エラーが起きたときは何も起きないまま終わらず、メッセージが出て Ruby コンソールに詳細が出る

## 3. 自由割付（仕様 18-3 / シナリオ D）

1. 石の上で右クリック →「ここに縦目地を追加」 → [ ] 石が 2 枚に分割
2. 目地を選択して Delete → [ ] 2 枚が 1 枚に結合
3. 芋目地で A|B の縦目地を削除 → AB と上の C の間の横目地を削除 → [ ] L 字の石。ソリッド
4. ロック → ドラッグ → [ ] 「ロックされた目地は移動できません」
5. 外周の境界を削除しようとする → [ ] 拒否される

## 4. 石厚・目地幅の変更（仕様 18-4）

1. 目地を数本動かし、L 字石も作っておく
2. 編集パネルで石厚 30 → 40 →「反映」
   - [ ] 目地位置・L 字の輪郭はそのまま、厚みだけ 40mm
   - [ ] 石の表面位置は変わらない（内側へ増える）
3. 目地幅 8 → 10 → [ ] 中心線は保持、隙間が 10mm
4. 1 回の元に戻すで設定変更前に戻る

## 5. R コーナー（仕様 18-5 / シナリオ B）

1. 平面図で 直線 2000 → 半径 500 の 90° 円弧 → 直線 2000 を描き、高さ 1800 で押し出す
2. 円弧部分のファセットを 1 枚だけ選択して「石割付を生成」
   - [ ] 直線〜円弧〜直線の全体が 1 つの割付対象として認識される（対象: line + arc + line、展開長 ≈ 4785.4）
   - [ ] 円弧を跨ぐ石が、表面も背面も曲面の 1 枚石として生成される（隙間・重なりなし）
   - [ ] 円弧部分の面のエッジが柔らかく表示される
3. 円弧部分の縦目地をドラッグ → [ ] 曲面に沿って動き、移動量は弧長で表示
4. ArcCurve 情報がない（分解した）円弧でも試す → [ ] 「円弧を推定しました」の注意が出る
5. 石厚を 600 にする → [ ] 「R500 では指定の石厚・オフセットを確保できません」で拒否、形状は変わらない

## 5b. 複数面・角の納まり

1. 2000 × 1500 × 高さ 1800 の箱を作り、側面 4 枚を選択（天面も一緒に選んでよい）
   - [ ] 天面は「対象から外しました」と注意が出て、側面 4 枚が一周の割付になる
   - [ ] 生成ダイアログに「角の納まり」カード（留め／左が勝ち／右が勝ち）が出る
2. 留めで生成 → [ ] 4 つの角で石が斜めに合い、目地幅 8mm、石どうしが重ならない
3. 左が勝ちで生成 → [ ] 左の石が角まで伸びて小口が見え、右の石は勝ち側の背面から 8mm で止まる
4. 編集モードで 1 つの角の近くを右クリック →「この角の納まり」→ 右の石を勝ちに
   - [ ] その角の石だけ作り直される（他の角は変わらない）。1 回の元に戻すで戻る
   - [ ] 「全体の設定に戻す」で元の納まりに戻る
5. L 字の入隅（壁 2 枚）でも 2〜4 を確認
6. 角の石を 20mm 幅にして勝ち負けにする → [ ] 「石が短すぎます」で拒否、形状は変わらない

## 6. 丸柱（仕様 18-6 / シナリオ C）

1. 半径 1000 の円を描き、高さ 2400 で押し出す。側面のファセットを 1 枚選択
2. 全体を均等に調整・馬踏みで生成
   - [ ] 周方向 7 分割（≈897.6mm）で最後の目地が閉合
   - [ ] 継ぎ目（開始位置）を跨ぐ石も正しい曲面石
3. 継ぎ目付近の目地をドラッグして継ぎ目を越える → [ ] 破綻しない
4. 開始位置を変えて再割付 → [ ] 割付が回転する

## 7. 保存・再編集（仕様 18-7 / シナリオ E）

1. 目地を数本動かし、1 本ロックし、石を 1 枚分割する
2. 保存して SketchUp を終了 → 再起動して開く
3. 割付グループを選んで右クリック →「石割付: 目地を編集」
   - [ ] 以前の目地位置・ロック状態・石厚が復元され、そのまま編集できる
4. 割付グループを移動・回転してから編集 → [ ] ハイライトとドラッグが正しい位置に出る
5. 割付グループの中に入った状態（グループ編集中）でも編集できる

## 8. 通常編集との関係（14 章）

1. 石グループを 1 つ開いてプッシュプルで変形 → 編集モードに入る
   - [ ] 「通常の編集ツールで変更されています」の警告
   - [ ] [はい] で作り直し / [いいえ] で切り離し
2. 石グループを 1 つ削除 → 編集モード → [ ] 欠落として検出、作り直せる
3. 切り離した石に接する目地を動かす → [ ] 拒否される

## 9. 例外（仕様 18-8）

- [ ] 石幅 0 / 石厚 -30 / 文字列 → ダイアログにエラー、何も生成されない
- [ ] 水平な面を含めて生成 → 「鉛直でない面」エラー
- [ ] 離れた 2 枚の壁を同時に選択 → 「選択した面が連続していません」
- [ ] Ruby コンソールで割付グループの `data` 属性を壊して編集 → 読み込みエラー表示、形状は消えない
